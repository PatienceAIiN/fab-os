# Third-party components (summary)

The complete, per-image list is generated by `scripts/source-offer.sh` into
`legal/source-offer/<image-id>/copyrights.txt`. Major components:

| Component | License | Role |
|-----------|---------|------|
| Ubuntu 26.04 LTS base system, Linux kernel 7.0 | GPL-2.0 and others | base OS, unmodified |
| systemd, systemd-boot | LGPL-2.1+ | init, boot loader (VM profile) |
| KDE Plasma 6, KWin, SDDM, Breeze | GPL-2.0+/LGPL | desktop, compositor, greeter, icons |
| Plymouth | GPL-2.0+ | boot splash engine (theme is ours) |
| Calamares | GPL-3.0+ | installer (ISO profile) |
| GRUB 2 (signed), shim-signed, casper | GPL-3.0+, BSD-2-Clause, GPL-2.0+ | ISO boot and live session |
| Firefox | MPL-2.0 | web browser, Mozilla's own unmodified .deb from packages.mozilla.org |
| PackageKit | GPL-2.0+ | package management service (origin label byte-patched, see PATCHED-BINARIES.md) |
| KDE applications (Konsole, Dolphin, Kate, Discover, Gwenview, Okular, Ark, Spectacle, KCalc, KWallet, KInfoCenter ...) | GPL-2.0+/LGPL-2.1+ | bundled applications, renamed in the UI through en@fabos catalogs (see PATCHED-BINARIES.md) |
| llama.cpp | MIT | local inference engine |
| Qwen2.5-1.5B-Instruct model weights (GGUF Q4_K_M, unmodified; Copyright 2024 Alibaba Cloud) | Apache-2.0 | built-in offline model, /usr/share/fabos/models |
| whisper.cpp + Whisper tiny.en ggml model | MIT | offline speech-to-text for "Hey Fab" (model fetched sha256-pinned at image build) |
| PocketSphinx + pocketsphinx-en-us | BSD-2-Clause | offline wake-word spotting |
| eSpeak NG | GPL-3.0+ | offline fallback voice (separate process) |
| Python 3, PyQt6 | PSF-2.0, GPL-3.0 | runtime for the Fab OS applications |
| anthropic Python SDK | MIT | Claude provider of the agent |
| Google Material Symbols | Apache-2.0 | glyphs in the FabOS icon theme |
| Inter, JetBrains Mono, Noto Sans | SIL OFL 1.1 | fonts |
| FabOS AI stack (aiosd, aios) | Apache-2.0 | Patience AI |
| Fab OS packaging and artwork | Apache-2.0 (artwork also CC0-1.0) | Patience AI |
