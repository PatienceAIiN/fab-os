# ADR-0008: Hiding upstream vendor names where it is safe

## Selected
- Never patch Ubuntu/KDE package files. Visible names are overridden through higher-priority XDG paths:
  `/usr/local/share/applications/*.desktop` (generated by `/usr/lib/fabos/rebrand-desktop-entries`, re-run by an
  apt Post-Invoke hook), `/usr/local/share/wayland-sessions/fabos.desktop` as the only SDDM session,
  Fab Wallet naming and a default wallet `FabWallet` via `/etc/xdg/kwalletrc`, KDE user-feedback KCM diverted.
- Not renamed: in-app "About" dialogs, KInfoCenter's "KDE Plasma Version" line, library names, package names.
  Those are factual attribution and renaming them would mean forking translations or binaries.

## Why
Users see Fab OS everywhere they act (launcher, session chooser, wallet prompts, settings entries) while KDE
and Canonical remain credited where the software itself reports its origin — which trademark policy expects.
