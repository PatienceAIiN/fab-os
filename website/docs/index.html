Fab OS

A Linux desktop built on Ubuntu and KDE Plasma, with optional local-first AI assistance and clear user controls.

Release status: Fab OS is under development. The public image is not published yet. Use a dedicated test device only when an approved release is available.

What it is

Fab OS aims to keep the familiarity of Linux while making useful assistance easier to access. People decide when assistance is used, what information is shared, and when work is complete.

How to evaluate it

  1. Use a spare device or replaceable test disk.
  2. Read the release notes and verify published checksums.
  3. Test boot, display, storage, network, audio, sleep, updates, and recovery.
  4. Record the exact hardware and any limitations.

Privacy and security

Fab OS is designed around minimal collection, visible network use, limited access, and user review. The final release notice will identify the applicable services, data practices, retention, and support contact.

Open source and licenses

Patience AI code and artwork are published under their stated licenses. Ubuntu, KDE Plasma, Linux, firmware, fonts, and other third-party components keep their own licenses and notices. Read LICENSE and the repository’s legal notices before redistributing.
