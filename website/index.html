The idea

A familiar base for a new kind of work.

Fab OS keeps the desktop recognizable and adds a considered layer for people who want helpful technology without unnecessary noise.

✦

Clear controls

Review important actions, pause assistance, and keep ordinary desktop work available without AI.

◌

Local-first by choice

Keep sensitive work close to the device where practical. Network-dependent features should be visible and optional.

Open foundation

Fab OS is built with Linux foundations and ships with applicable source, license, and attribution notices.

The public promise

Simple on the surface. Considered underneath.

The product experience is designed around a few ideas that are easy to explain and easy to remember.

01

People decide

Assistance can suggest a next step, but important choices remain yours.

02

Boundaries stay visible

You should be able to understand when work is local, networked, or waiting for your review.

03

Recovery matters

Early software should be tested carefully, with backups and a practical path back when supported.

Public pre-release

Download Fab OS™ 1.0.

One file. Download the disc image, write it to a USB stick, and start your computer from it. No accounts, no reassembly. Fab OS runs live first, so you can try it before installing; the installer is on the desktop.

  1. Download the ISO (about 4 GB; it includes the offline AI model and voice).
  2. Write it to an 8 GB USB stick with Balena Etcher.
  3. Restart and choose the USB stick to boot.
  4. Try it live, then open Install Fab OS.

Pre-release software: expect rough edges and please report them. Ubuntu is a trademark of Canonical Ltd.; KDE and Plasma are trademarks of KDE e.V.; Fab OS is an independent project.
