The operating system that does the work.

Fab OS is a Linux desktop with an autonomous AI agent built into the OS itself. Tell it what you want in plain language. It opens apps, writes files and code, sends mail, watches for replies, and reports back — every step checked by a deterministic policy you control.

Do it

An agent at the OS level, not an app on top

The agent lives in the system: a per-user service with a command bar on the desktop, a Command Center, KRunner integration, a right-click menu in the file manager, and a CLI. New applications become usable by the agent the moment they are installed.

01

Ask, then let go

“Open the editor, write hi, mail it to Harsh and tell me when he replies.” The agent plans, executes, verifies and schedules the watch. You get a notification when the reply lands.

02

Everything a computer can do

Shell, files, applications, typing into live windows, email (IMAP/SMTP), web, background watches, follow-up tasks. Coding tasks create a project, write tests, run them and fix failures.

03

Complete history

Every task, step, tool call, approval and notification is recorded. Cancel, retry, edit or delete anything. Nothing is claimed that did not verifiably happen.

04

Your model, your choice

Claude, OpenAI, Google Gemini, or a fully offline local model. Keys are encrypted with systemd-creds and never leave the machine except to the provider you picked. System-Wide AI has an off switch.

AI proposes. Policy verifies. The OS executes.

The model is probabilistic; the operating system is not. Every action the agent wants to take passes a deterministic risk classifier before it runs.

About Fab OS

Built by Patience AI, an Indian AI company, on the belief that the next operating system is not a chat window bolted onto a desktop — it is a desktop whose native capability is getting things done for you, safely.

Ubuntu, unchanged, underneath

Every Ubuntu package, command and update works. Security updates flow from Ubuntu; Fab OS features flow from Patience AI’s signed repository. No snap.

Local-first and honest about it

No telemetry. Cloud AI only when you enable it, with a visible indicator. Feedback and bug reports go to Patience AI through a channel you trigger yourself.

Install

Two ways: the Fab OS image, or add Fab OS to an existing Ubuntu 26.04 LTS system in one command.

On Ubuntu 26.04 LTS

sudo curl -fsSL https://fabricos.patienceai.in/apt/fabos-archive-keyring.gpg -o /usr/share/keyrings/fabos-archive-keyring.gpg
echo 'deb [signed-by=/usr/share/keyrings/fabos-archive-keyring.gpg] http://fabricos.patienceai.in/apt loom main' | sudo tee /etc/apt/sources.list.d/fabos.list
sudo apt update && sudo apt install fabos-desktop-meta

Then log out and choose the Plasma (Fab OS) session. The Fab OS Updates app lets you pick the Standard or Beta channel and turn automatic updates on.

Questions

Does it need the cloud?

No. With a local model it is fully offline. Cloud providers are optional and off until you add a key.

Can the agent break my system?

Privileged and destructive actions are CRITICAL/HIGH risk and require your approval in the default mode. Everything is logged; file operations inside a task can be reviewed step by step.

What about my data?

Nothing is collected by Fab OS. Only the text of a task and the tool results the agent needs are sent to the provider you chose.

Is it stable?

The base is Ubuntu 26.04 LTS. The Fab OS layer is new — use the Standard channel unless you want to test early features on Beta.
